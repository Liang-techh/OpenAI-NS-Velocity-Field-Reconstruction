# Contributor contract

This is the curated ST054 release repository. The archived full-paper reconstruction and ongoing experiment repository are separate scopes.

Preserve frozen candidate bytes, MAT data, source pins and independent evidence. Do not promote `pde_validated`, source identity, paper-exactness or blow-up flags from software tests. No residual-defined free forcing or threshold rescaling is allowed. New candidates need new IDs, explicit physical contracts, frozen parameters and independent validation.

Read README.md and docs/MODEL.md, docs/VALIDATION.md and docs/PROVENANCE.md. Run the Python release tests and, for MATLAB changes, native numerical/UI callback tests. Record the actual runtime/version and executed commands; mark unexecuted tests as not run. Never invent screenshots, CI outcomes, source hashes or proof certificates.

Keep the current documentation and interface English. Do not force-push, bulk-delete old branches/issues or overwrite other agents' work. A public release update is not permission to close the scientific target. Use an isolated branch and review the latest main before merge.
