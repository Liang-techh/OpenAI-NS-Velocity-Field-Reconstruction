# Publication maintenance contract

This repository is the runnable ST054 publication, not the ongoing experiment stack. Read README.md, candidates/registry.json and docs/SCIENTIFIC_STATUS.md first.

- Do not call a software test pass a PDE proof or change the original scientific gates.
- Preserve parameter hashes and the distinction between original and reconstructed JSON.
- Do not fit or modify published fields during packaging or visualization work.
- New research needs new IDs, complete arrays, immutable source bindings and independent validation.
- Keep active documentation, UI labels, comments and new commit messages in English.
- Never merge a pre-replacement PR without reconciling its entire diff against the new publication.
- The old working tree is retained in archive/pre-st054-replacement-2026-09-19.
- Do not force-push, delete other branches, alter schedules or change repository visibility.
