## Executable mapping

`src/openai_ns_reconstruction/axis_reference_angular_jets.py` extends the landed `axis_reference_pair.py` from parameter order `m=0` to arbitrary finite `m` for the angular component only.

- `sigma` is obtained only through `actual_schedule_reference_pair`, hence through the already-landed no-sampling low-|Z| SchedulePressure margin witness.
- `epsilon` is obtained only from `certify_actual_schedule_analytic_inputs(...).neighborhood.epsilon = rho/2`; callers cannot inject an unrelated coefficient radius.
- `H` is treated as its exact cubic polynomial, so its Taylor jet terminates after order three.
- `chi` derivatives are generated by finite Taylor-series multiplication and reciprocal recurrences for the exact rational formula `H^2/(H^2+sigma^2)`.
- `phi0` jets are generated by the exact radial recurrence `phi[n+1] = (-chi/2) phi[n] / radialDivisor(2,n)`, applied in Taylor algebra. No finite-difference derivative or fitted coefficient enters production.
- `parameter_jet(n,m,eta)` returns the actual derivative represented by the normalized Taylor coefficient times `m!`.
- `normalized_axis_coordinate` divides that derivative by the exact printed AxisSpace weight at the actual certified epsilon. It is a pointwise coordinate, not a new global norm proof.

Regression tests independently check the first derivative against the differentiated closed form and check successive jets through an FTC integral identity. They also require `m=0` to agree with the previously landed actual SchedulePressure reference coefficients.

## Remaining boundary

This increment does **not** yet materialize a complete `AxisCoefficientSpace.AxisSpace` reference pair. In particular:

1. the axial reference coefficient `u0[1]=-(1/2) inverseL*zStar` still lacks arbitrary actual eta derivatives; obtaining them theorem-faithfully requires higher derivative access to the actual SchedulePressure datum rather than finite-difference fitting;
2. this executable jet evaluator does not independently prove the global weighted norm bound for every `(n,m)` (the existing analytic/resolvent majorant remains the theorem-side norm certificate);
3. `coefficientOperators`, `naturalRemainder`, and the first genuine Picard step are not yet executed on a complete compatible pair;
4. `phi/u/average/pressure`, `NaturalProfileAssembly`, and support/moment/matching/cone conditions therefore remain unresolved;
5. `paper_exact_velocity_available` must remain `false`.

The next smallest blocker is to construct the actual SchedulePressure higher-eta derivative jet needed by `zStar`, thereby materializing the axial half of the reference pair with the same FTC-compatible derivative interface. Once both halves are available, the landed operator/remainder formulas can be connected to the first real Picard iterate.
