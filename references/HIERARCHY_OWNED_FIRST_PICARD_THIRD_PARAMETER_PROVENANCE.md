## Paper location and identity

Section 5, Eq. (5.7), writes

`d_xi W_n + xi^-1 diag(0,0,2,0,3,1) W_n = A0 W_n + A1 d_eta W_n + f_n`,

with zero axis datum. Lemma 5.1 introduces the singular inverse

`(G g)_i(xi,eta) = integral_0^xi (s/xi)^c_i g_i(s,eta) ds`,

`c=(0,0,2,0,3,1)`, and the Picard expansion generated by `K=G(A0+A1 partial_eta)`. The first image is `W_n^(0)=G f_n`.

The kernel `(s/xi)^c_i` and integration limits are independent of `eta`. Hence for the finite analytic jet used by this Stage-2 constructor,

`partial_eta^r W_n^(0) = G(partial_eta^r f_n)`, for `0 <= r <= 3`.

`src/openai_ns_reconstruction/background_repaired_history_picard_first_third_parameter.py` implements exactly this identity. The value row delegates to the landed `first_picard_term_eq_5_7`; derivative rows call the same landed singular inverse on the hierarchy-owned analytic forcing derivatives.
