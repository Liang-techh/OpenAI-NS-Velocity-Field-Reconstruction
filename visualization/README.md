# Visualization entry points

Use the repository-root `start_here.m` launcher. The implementation and bundled data are in `matlab/`.

| Entry | Purpose |
|---|---|
| `start_here` | Selected full-field presentation preset |
| `start_here('full')` | General full-field explorer |
| `start_here('core')` | Corrected dense local-core view with geometry diagnostics |
| `ns_core_timeseries` | Fixed-window metric curves and table |

See the [complete guide](../docs/VISUALIZATION.md). No visual control changes the candidate coefficients. Instantaneous streamlines are not particle paths, and displayed residuals are not independent scientific acceptance.
